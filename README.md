# 손준혁 | 관심 분야 · 취미 · 이력

로그인 없이 누구나 열람할 수 있는 정적 웹사이트입니다. (GitHub Pages)

- **공개 페이지 주소**: https://sonjunhyek2.github.io/sjh-interducemyself/
- **공개 소스 코드 저장소**: https://github.com/sonjunhyek2/sjh-interducemyself

## 페이지의 대상과 목적

방문자에게 내가 어떤 관심 분야와 취미를 가졌고 어떤 이력을 쌓아왔는지 진솔하게 보여 주기 위해 만든 페이지입니다.

## 공개하는 정보 (3개 이상)

1. **관심 분야**: 시스템 아키텍처, 컴퓨터 사이언스 기본기 및 알고리즘, 인터랙티브 웹 디자인
2. **취미**: 알고리즘 문제 풀기, 기술 블로그 탐독, 산책과 음악 감상
3. **이력**: 학사 전공 및 정보처리기사 CS 학습 발자취

## 공개하지 않는 정보 (3개 이상 - 페이지와 소스 코드에 일체 미포함)

1. **전화번호**: 개인 연락처 보호를 위해 미포함
2. **집 주소**: 사생활 및 상세 거주지 정보 비공개
3. **학교 이름**: 출신 학교 이름 비공개 원칙 (전공 분야만 표기)

## 5개 페이지 구조 및 네비게이션 연동

```
index.html        메인 진입점 (관심 분야 · 취미 · 이력 탐색 허브)
interests.html    관심 분야 페이지 (시스템 구조, CS 기초, 웹 디자인)
hobbies.html      취미 페이지 (알고리즘 풀이, 블로그 탐독, 음악 감상)
history.html      이력 페이지 (기술스택 제외, 학력 전공 및 학습 타임라인)
info.html         공개 정보 페이지 (대상·목적 명세, 공개/비공개 정보 목록)
css/custom.css    공통 커스텀 스타일 (글래스모피즘, 링 애니메이션 등)
js/main.js        모바일 메뉴 토글 및 GSAP 스크롤 모션
js/theme.js       다크/라이트 테마 제어
js/tailwind-config.js Tailwind CSS 설정
.nojekyll         Jekyll 처리 비활성화
```

계정 생성, 로그인, 인증, 초대, 비밀번호, OAuth, CAPTCHA 없이 새 시크릿 창에서 즉시 열립니다.
