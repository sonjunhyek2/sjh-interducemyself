페이지의 대상과 목적

이 페이지는 IT 채용 담당자에게, 탄탄한 CS 기본기로 빠르게 성장하며 맡은 일을 끝까지 해내는 개발자임을 보여 주기 위해 만들었습니다.

공개하는 정보 (4개)

  • 이름과 개발자 소개: 손준혁 개발자의 가치관 및 성장 지향점
  • 학력 및 학습 이력: 전남대학교 전자상거래 전공 및 정보처리기사 준비 이력
  • 기술 스택과 프로젝트: Spring Boot 기반 실무/학습 프로젝트 상세 내역
  • GitHub 공개 저장소 주소: 소스 코드를 누구나 열람할 수 있는 GitHub 링크

공개하지 않는 정보 (4개)

  • 전화번호: 개인 연락처 보호를 위해 포함하지 않음
  • 집 주소: 상세 거주지 정보 비공개
  • 주민등록번호 및 생년월일: 민감 고유식별정보 배제
  • 계정 및 인증 정보: 이메일 주소, 비밀번호, API 키, 토큰 미포함

원칙 준수 안내: 비공개로 정한 정보는 비밀번호 등으로 가려둔 것이 아니라, 웹 페이지 화면과 공개 소스 코드 어디에도 아예 넣지 않았습니다.

본 웹사이트의 모든 페이지와 GitHub 소스 코드는 계정 생성, 로그인, 인증, 비밀번호, OAuth, CAPTCHA 없이 새 시크릿 창에서 즉시 열람할 수 있습니다.
